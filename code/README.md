Code layout:

- `generate_figures.py`: one-click entry for regenerating the figures used by the slides.
- `models/`: model definitions and model-specific training/evaluation scripts.
- `tools/`: data inspection and diagnostics helpers.
- `datasets/`: local OxIOD-derived data files used by the experiments.
- `checkpoints/`: saved model weights.

Top-level files that remain in `code/` are the current figure-generation entry point,
environment metadata, and data files.
